# VentureScope AI - Database Schema v1

## Database Design Goals

The database must:

1. Support startup intelligence workflows.
2. Support analytics and machine learning.
3. Enable graph relationship analysis.
4. Support explainable predictions.
5. Scale beyond the MVP.

---

# Database Layers

## Layer 1: Raw Data

Stores collected information directly from external sources.

## Layer 2: Processed Metrics

Stores cleaned and transformed startup metrics.

## Layer 3: Feature Store

Stores ML-ready features.

## Layer 4: Predictions

Stores model outputs and explanations.

## Layer 5: Insights

Stores AI-generated intelligence.
