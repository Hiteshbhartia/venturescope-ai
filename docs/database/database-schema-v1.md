# VentureScope AI - Database Schema v1

## Database Design Goals

The database must:

1. Support startup intelligence workflows.
2. Support analytics and machine learning.
3. Enable graph relationship analysis.
4. Support explainable predictions.
5. Scale beyond the MVP.

---

# Database Layers

## Layer 1: Raw Data

Stores collected information directly from external sources.

## Layer 2: Processed Metrics

Stores cleaned and transformed startup metrics.

## Layer 3: Feature Store

Stores ML-ready features.

## Layer 4: Predictions

Stores model outputs and explanations.

## Layer 5: Insights

Stores AI-generated intelligence.

# Relationships

## Industry → Startups

Relationship:

1 : N

One industry can contain many startups.

---

## Startup → Founders

Relationship:

N : M

Implemented using:

startup_founders

A founder can build multiple startups.

A startup can have multiple founders.

---

## Startup → GitHub Metrics

Relationship:

1 : N

Each startup can have multiple GitHub snapshots over time.

---

## Startup → Product Hunt Metrics

Relationship:

1 : N

Each startup can have multiple Product Hunt records.

---

## Startup → News Mentions

Relationship:

1 : N

Each startup can have many news mentions.

---

## Startup → Startup Scores

Relationship:

1 : N

Scores are recalculated periodically.

---

## Startup → Startup Features

Relationship:

1 : N

Features are generated for each snapshot period.

---

## Startup → Predictions

Relationship:

1 : N

Predictions can be generated by multiple model versions.

---

## Prediction → Prediction Explanations

Relationship:

1 : N

Each prediction may contain multiple feature explanations.
